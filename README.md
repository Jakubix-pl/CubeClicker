# CubeClicker demo

Play the Red Dwarf demo in your browser:
https://jakubix-pl.github.io/CubeClicker-demo/

Download the Windows demo:
https://github.com/Jakubix-pl/CubeClicker-demo/releases/latest

Grow from an atom to Red Dwarf, Prestige for lasting upgrades, and rebuild.
The demo includes early production, upgrades, and progression through the first star.

This repository contains compiled demo builds and their license notices.
It does not contain the full game source or its Git history.
Browser saves remain in your browser. Clearing site data clears your progress.
